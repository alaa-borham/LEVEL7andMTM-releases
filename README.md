# LEVEL7 and MTM — التحديثات

## تنزيل البرنامج الكامل (ويندوز)

**https://github.com/alaa-borham/LEVEL7andMTM-releases/releases/latest**

كل إصدار يعتمده المدير يُبنى هنا تلقائياً (`.github/workflows/windows-program.yml`): يُتحقق أولاً من توقيع المدير على قائمة ملفاته، ثم يُجرَّب على ويندوز حقيقي، ثم يوضع في صفحة الإصدارات. فك الملف، ثم افتح «LEVEL7 - first run.cmd» أول مرة فقط، وبعدها «LEVEL7 and MTM.exe». لا يعمل إلا باسم مستخدم وكلمة سر من المدير، وعلى جهاز يوافق عليه.

## محتوى المستودع

هذا المستودع يحمل **البرنامج المبني والمشوَّش فقط**، كما يصل للأجهزة:

- `level7-cad/releases/latest.json` — الإصدار الأحدث وقائمة ملفاته (بصمة كل ملف).
- `level7-cad/releases/app/` — ملفات البرنامج المشوَّشة.
- `level7-cad/releases/manifests/` — قائمة ملفات كل إصدار (يعتمدها المدير).
- `level7-cad/releases/approvals/` — اعتمادات المدير للإصدارات (موقّعة بمفتاحه).
- `level7-cad/policy/policy.json` — صلاحيات المستخدمين (موقّعة بمفتاح المدير، بلا أسماء ولا كلمات سر).

الكود المقروء في مستودع خاص. لا تُقبل أي صلاحية أو تحديث لم يوقّعه مفتاح المدير.
